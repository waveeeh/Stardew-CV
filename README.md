# 🧑‍🌾 Stardew Valley Inspired CV

An interactive, pixel-perfect resume website inspired by the UI and aesthetic of *Stardew Valley*. This project serves as a creative, gamified portfolio to showcase my frontend development skills, previous work, and tech stack.

## 🛠️ Tech Stack
* **Build Tool:** Vite (keeping it ultra-fast ⚡)
* **Frontend:** HTML5, CSS3, JavaScript / React
* **Styling:** Custom retro/pixel CSS layouts
* **Deployment:** Hosted on Vercel

## 🎮 Features & Highlights
* **Themed UI:** Replicates the iconic dialogue boxes, fonts, and menus from the game.
* **Interactive Elements:** Explore my education, skills, and projects as if you're checking your in-game inventory.
* **Fully Responsive:** Optimised for a seamless transition from desktop monitors to mobile screens.
